# RFC 6265 — HTTP State Management Mechanism

원본: `raw/rfc6265.txt`. rfc-editor.org에서 받은 원문 그대로다 (2026-10-15).
2011년 4월에 나온 IETF Standards Track 문서로, RFC 2965를 대체한다 (raw/rfc6265.txt:7-14). 쿠키(`Set-Cookie`, `Cookie` 헤더)를 정의한다.

## 과제와 관련된 절

보너스 쿠키·세션은 서버 쪽만 구현하므로 서버 요구사항 위주로 다룬다.

| 절 (시작 줄) | 내용 | 위키 페이지 |
|---|---|---|
| 3 Overview (293) | 쿠키가 오가는 방식, `Set-Cookie` 여러 개 | [[concepts/bonus]] |
| 4.1 Set-Cookie (426) | 문법, 속성 (Expires, Max-Age, Path, Secure, HttpOnly) | [[concepts/bonus]] |
| 4.2 Cookie (690) | 요청 헤더 문법과 의미 | [[concepts/bonus]] |
| 6.1 Limits (1465) | 쿠키 크기·개수 | [[concepts/bonus]] |
| 8.4 Session Identifiers (1714) | 세션 식별자, session fixation | [[concepts/bonus]], [[concepts/security]] |

다루지 않는 절: 5 User Agent Requirements(브라우저 쪽), Domain 속성 세부, 7 Privacy, 9 IANA.
