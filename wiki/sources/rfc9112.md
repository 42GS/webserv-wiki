# RFC 9112 — HTTP/1.1

원본: `raw/rfc9112.txt`. rfc-editor.org에서 받은 원문 그대로다 (2026-10-15).
2022년 6월에 나온 IETF 표준(STD 99)이다. RFC 7230의 일부를 대체한다 (raw/rfc9112.txt:6-11, raw/rfc9112.txt:24).
HTTP/1.1의 메시지 문법, 파싱, 연결 관리, 관련 보안 문제를 다룬다 (raw/rfc9112.txt:20-22). 메서드·status code의 의미는 [[sources/rfc9110]] 소관이다.

## 핵심 규칙

- HTTP/1.1 요청에 Host가 없거나, 두 줄 이상이거나, 값이 잘못되면 400 (MUST, raw/rfc9112.txt:445-448).
- `Content-Length`도 `Transfer-Encoding`도 없는 요청은 본문 길이가 0이다 (raw/rfc9112.txt:980-981).
- 받는 쪽은 chunked를 파싱할 수 있어야 한다 (MUST, raw/rfc9112.txt:807-808, raw/rfc9112.txt:1071-1072).
- HTTP/1.1은 기본이 persistent connection이다 (raw/rfc9112.txt:1337-1340).

## 과제 문서와의 충돌·질문

- 단계적 종료(half-close)에 필요한 `shutdown`이 허용 함수에 없다 → [[analysis/subject-vs-evaluation]]
- subject는 HTTP/1.0을 기준점으로 제안하지만, HTTP/1.1로 응답하면 persistent가 기본이 된다 → [[analysis/subject-vs-evaluation]]
