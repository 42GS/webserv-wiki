# RFC 2046 — MIME Part Two: Media Types

원본: `raw/rfc2046.txt`. rfc-editor.org에서 받은 원문 그대로다 (2026-10-15).
1996년 11월에 나온 IETF Standards Track 문서다 (raw/rfc2046.txt:7-16). `multipart/form-data`는 이 문서 5.1절의 multipart 모델을 따른다 (raw/rfc7578.txt:177-179).

## 다루는 범위

이 위키는 **5.1 Multipart Media Type**(raw/rfc2046.txt:934-1300)만 다룬다. 나머지(text·image·audio·video·application·message 타입, 다른 multipart 하위 타입)는 과제와 관련이 없다.

| 부분 (시작 줄) | 내용 | 위키 페이지 |
|---|---|---|
| 5.1 (934) | part 구조, 구분자가 part 안에 나오면 안 됨 | [[concepts/file-upload]] |
| 5.1.1 Common Syntax (1015) | 구분자 줄, 앞 CRLF의 소속, 마지막 구분자, preamble·epilogue, boundary 문자, BNF | [[concepts/file-upload]] |

## 핵심

- 구분자 줄은 `--` + boundary + 선택적 공백 + CRLF (raw/rfc2046.txt:1023-1026).
- 구분자 앞의 CRLF는 앞 part가 아니라 구분자에 속한다 (raw/rfc2046.txt:1073-1076).
- 마지막 구분자는 끝에 `--`가 더 붙는다 (raw/rfc2046.txt:1095-1101, raw/rfc2046.txt:1251).
- 받는 쪽은 첫 구분자 앞과 마지막 구분자 뒤의 내용을 무시해야 한다 (raw/rfc2046.txt:1110-1112).
