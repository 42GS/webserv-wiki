# RFC 7578 — Returning Values from Forms: multipart/form-data

원본: `raw/rfc7578.txt`. rfc-editor.org에서 받은 원문 그대로다 (2026-10-15).
2015년 7월에 나온 IETF Standards Track 문서로, RFC 2388을 대체한다 (raw/rfc7578.txt:7-10). 폼 입력 결과를 돌려보내는 `multipart/form-data` 미디어 타입을 정의한다 (raw/rfc7578.txt:18-22).

## 과제와 관련된 절

| 절 (시작 줄) | 내용 | 위키 페이지 |
|---|---|---|
| 1 Introduction (97) | HTML 폼에서 나왔고 브라우저·서버에 널리 구현됨 | [[concepts/file-upload]] |
| 4 (175), 4.1 boundary (184) | part를 boundary로 구분 | [[concepts/file-upload]] |
| 4.2 Content-Disposition (195) | 필드 이름(`name`), 파일 이름(`filename`) | [[concepts/file-upload]] |
| 4.3 여러 파일 (246) | 같은 `name`의 별도 part | [[concepts/file-upload]] |
| 4.4 part의 Content-Type (262) | 기본 `text/plain` | [[concepts/file-upload]] |
| 4.7 (321), 4.8 (343) | Content-Transfer-Encoding 비권장, 그 밖의 헤더는 무시 | [[concepts/file-upload]] |
| 7 Security (480) | 파일 이름으로 덮어쓰기 주의, 실행 가능한 내용 | [[concepts/security]] |

다루지 않는 절: 문자셋 처리(4.5, 4.6, 5.1), IANA 등록(6, 8), 부록.

## 이 문서로 확인하지 못한 것

- boundary 구분자의 정확한 문법(마지막 구분자 등). 이 문서는 RFC 2046 5.1절의 multipart 모델을 따른다고만 한다 (raw/rfc7578.txt:177-179) → [[source-wishlist]].
