# RFC 3875 — The Common Gateway Interface (CGI) Version 1.1

원본: `raw/rfc3875.txt`. rfc-editor.org에서 받은 원문 그대로다 (2026-10-15).
2004년 10월, Apache Software Foundation 저자들이 쓴 문서다 (raw/rfc3875.txt:7-13).

> [!warning] 문서 성격
> IETF 표준이 아니라 **Informational** RFC다 (raw/rfc3875.txt:9). IESG는 이 문서가 보안 등에 대한 IETF 검토를 거치지 않았으니 구현 가치를 평가할 때 주의하라는 노트를 붙였다 (raw/rfc3875.txt:27-34).
> 그래도 subject가 요구하는 CGI(raw/subject.md:175-182)를 정의한 문서이므로 CGI 동작의 근거로 쓴다.

## 핵심 규칙

- 서버는 CGI에 대해 application gateway로 동작한다 (raw/rfc3875.txt:423). 스크립트가 규격을 어겨도 클라이언트에 대한 프로토콜 책임은 서버에 남는다 (MUST, raw/rfc3875.txt:433-437).
- 요청 본문의 transfer coding은 서버가 제거하고 `CONTENT_LENGTH`를 다시 계산한다 (MUST, raw/rfc3875.txt:1093-1095).
- 서버는 스크립트 출력을 EOF까지 모두 읽는다 (MUST, raw/rfc3875.txt:1522-1524).
- UNIX에서 메타변수는 같은 이름의 환경 변수로 전달하고, 작업 디렉토리는 스크립트가 있는 디렉토리로 한다 (raw/rfc3875.txt:1554-1566).
